# Prueba IA - Streamlit Application

Aplicación web interactiva desarrollada con **Streamlit** y Python, creada con la asistencia de Inteligencia Artificial.

## 🚀 Características
- Interfaz moderna y adaptable (`wide layout`).
- Panel lateral interactivo con navegación por secciones.
- Gráficos dinámicos y métricas en tiempo real.
- Estructura limpia y lista para escalar.

## 🛠️ Requisitos previos
- Python 3.8 o superior instalado.

## 📦 Instalación y ejecución local

1. Clona o descarga este repositorio.
2. Abre una terminal en la carpeta del proyecto (`Dev/prueba-ia`).
3. Crea y activa un entorno virtual (recomendado):
   ```bash
   python -m venv .venv
   # En Windows (Git Bash / PowerShell):
   source .venv/Scripts/activate
   ```
4. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
5. Ejecuta la aplicación de Streamlit:
   ```bash
   streamlit run app.py
   ```
